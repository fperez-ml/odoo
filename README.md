# Odoo

Un repositorio donde se guardarán los ficheros necesarios para un despliegue de Odoo en Docker, así como ficheros de configuración


## Instalación

### Docker
Instalación via Docker Compose

- Nombre base de datos. Se define en la web de instalación. Recomendado `myodoo`
- Contraseña. También se define en la web de instalación. Recomendado `myodoo`

## Login
- usuario. El correo electrónico establecido en la web de instalación
- contraseña la misma que se indicó en la web de instalación
